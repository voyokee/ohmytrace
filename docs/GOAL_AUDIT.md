# 对参考目标的逐项核对

本表覆盖完整目标，不以本轮已完成的子集替代总体完成标准。

| 目标 | 当前实现与证据 | 判定 |
|---|---|---|
| 地形风格化 | 30 倍展示 DEM、独立真实近景、细分网格、坡面/山谷/雪线、海岸材质；实际全球与雪山截图 | 系统已实现；山体美术继续迭代 |
| 实际三维植被 | 针叶、阔叶、白桦、热带、灌木、樱花、草七类原创 GLB，分枝/树冠轮廓/明暗；可重复生成 | 已实现；枝叶仍比参考简化 |
| 生态分布 | 影像颜色、海拔/树线/纬度、城市/水域/陡壁排除，草原/那拉提分开处理，稀疏戈壁 | 已实现；简化推断有误差 |
| 性能化植被 | GPU instancing、全球分块、近远 LOD、视距/背面裁剪、懒加载、取消与销毁 | 已实现，自动和运行时检查 |
| 地点模板 | 六类核心模板及戈壁；树种、密度、色调、雾、粒子、镜头按地点选择 | 已实现；多个实际地点已观察 |
| 季节与生命感 | 顶点风摆、近处草丛、春季花瓣、白桦金叶和冬雪、雪/萤火/浮尘 | 已实现；不代表物候实况 |
| 大气 | 分层高云、局部薄雾、云影、雪/花瓣等，近景保留空气透视 | 已实现轻量方案；非完整体积云 |
| 相机与旅行 | 全球、飞入、地点/沉浸、离开、回放；代次票据拒绝旧回调，按模板取景 | 已实现；极端山地取景可继续优化 |
| 性能分级 | 设备纹理/实例/LOD/粒子预算，自适应像素，静止按需/后台暂停，精确查询加速和缓存回收 | 已实现机制；高山大视口尚未达到帧率目标 |
| 画面与 UI | 亚洲构图、银河/薄蓝边、太阳侧光、足迹暖光、玻璃时间轴、现有数据工具 | 已实现；整体电影感与参考仍有差距 |
| 回归与交付 | npm test、619 原生几何对照、场景截图/指标、Git 提交、本地预览和可打包静态源码 | 本轮交付检查，详见 VALIDATION.md |

后续优先级：高山场景 GPU 开销与稳定取景，其次更细的针叶/阔叶枝叶、接触阴影和山体美术；保持真实地理底座、日夜与旅行数据功能。
