# 地球首页与操作流程讨论稿

日期：2026-10-29。状态：待讨论，尚未替代 PRODUCT.md，也不代表现有实现。

## 已确定的方向

- 地球是首页，也是浏览城市、旅行和人生阶段的共同空间。
- 底部默认展示最近一段旅行，只显示一张主卡片。
- 照片、地点顺序与回放支撑回忆；避免把首页做成分散的卡片信息流。
- 先梳理用户路径，再据此调整 I3 模块边界与 I4 范围。

## 一、页面结构

### 1. 地球首页：唯一主页面

```text
OnceHere                              我的
全部时间 ▾                 23 座城市 · 12 段旅行


                 可旋转的地球
              城市足迹与选中地点

                              回到全貌

┌───────────────────────────────────┐
│ 最近旅行                     全部旅行 › │
│ [小封面] 呼伦贝尔之旅                  │
│          9.28–10.1 · 4 座城市          │
│          [重走这段旅行]             ⋯ │
└───────────────────────────────────┘
```

数字、标题与日期只是布局示例。日期按已有精度显示，不补造天数。

- 首页没有并列的“地球／回忆”底部导航，旅行从主卡片进入。
- 初次打开显示所有足迹，最近旅行只是推荐查看的内容，不自动把镜头拉走。
- “最近”按旅行的已知发生日期排序，不按导入时间；无日期记录在列表中单列。
- 点卡片主体后才选中旅行、定位其范围；点“重走”直接进入对应回放。
- 新导入的旧旅行用临时通知提示，避免冒充最近发生的旅行。
- 回到全貌只重置镜头与当前选择，保留所选年份／阶段；“全部时间”另外负责清除时间筛选。
- 初版不在首页常驻搜索、播放速度、近看、夜景、编辑、导出等按钮。
- “我的”保留添加照片入口；空状态和增量导入提示可提供直接入口。

### 2. 底部内容层：同一容器的三种高度

| 高度 | 内容 | 地球行为 |
|---|---|---|
| 收起 | 单张最近／当前旅行摘要 | 地球保持可操作 |
| 半展开 | 标题、日期、地点概览、少量照片、回放与分享 | 地球仍露出主要区域，选中旅行只展示自己的连接 |
| 全展开 | 完整照片或旅行目录，顶部有明确标题与返回 | 保留镜头上下文，停止被遮挡画面的持续动画 |

点卡片或上拉进入详情；继续上拉看完整内容。提供等价的点击按钮，不依赖手势。
全展开返回半展开，再返回原摘要。地球上的选择、时间范围和列表位置需要保留。
旅行目录、照片、编辑、分享在同一个内容层内切换，不叠多层抽屉。

### 3. 全部旅行

- 按年分组的紧凑目录：小封面、短标题、日期、城市数。
- 支持城市名／旅行名查找；搜索在目录内，不常驻地球首页。
- 点一段旅行，目录退到半展开详情，地球定位该旅行。
- 返回目录保留筛选、搜索和滚动位置。
- 不放推荐文章、运营卡片或无关发现内容。

### 4. 城市详情

- 点地球的城市标记，展示城市名称、当前时间范围内的到访次数、照片和相关旅行。
- 同一城市多次到访放在同一个城市详情中，按日期选择具体一次。
- 选择具体到访后，展示该次照片；进入所属旅行是显式操作，不把其他到访混入。
- 城市详情与旅行详情共用底部容器，不另开常驻页面。
- 聚合点先放大或展示紧凑城市列表，不能直接当作单座城市。

### 5. 时间与人生阶段

- 首页只有一个“全部时间／某年／某阶段”的范围入口。
- 展开后选全部、年份，或进入“人生阶段”列表；避免同时常驻年份条和阶段条。
- 选择后，足迹、统计、旅行目录、照片范围与回放／分享入口使用同一范围。
- 年份与阶段暂时互斥，减少复合筛选规则；城市／旅行是该范围中的当前选择。
- 阶段提供名称、已知时间和关联城市，命名与调整在阶段详情完成。
- 阶段可重叠，记录在阶段间可以复用，但统计按实体去重，不能相加出重复总数。
- 首版采用可读的阶段列表，不要求首页展示完整人生色带时间轴；该取舍待确认。
- 跨年旅行在各重叠年份可见，仍是同一段旅行。范围内的照片与已知停靠高亮，其他部分明确提示“跨年旅行，另有年份外记录”；不悄悄扩大全局范围。

### 6. 我的

- 添加照片／导入进度。
- 数据保护：备份、恢复、上次备份时间、本机存储状态。
- 显示与播放设置：日夜景、画质、减少动态效果。
- 隐私与权限：本机处理说明、权限状态、删除应用内记录。
- 高级：CSV／记录文件导入、开放格式导出、重新整理、原有高级编辑。

“我的”是独立的管理页，返回后恢复原地球状态。恢复与重新整理明确说明影响；
删除应用内记录不等于删除系统相册原图，入口和确认文案区分两者。

## 二、完整操作流程

### A. 第一次打开

1. 直接出现地球。底部空卡片：“把照片里的旅行，点亮在地球上”，主按钮“从相册开始”；提供“先看看示例”，示例与私人记录明确分开。
2. 点开始后，用短说明解释读取照片时间与照片位置、原图留在本机、记录默认私密，再进入系统授权。网页直接选择文件／目录，不索取设备实时位置。
3. Android 可选可访问照片；用户拒绝时保留地球，展示重新授权／手动添加入口，不循环弹权限。
4. 底部显示真实扫描进度，地球逐步点亮已可靠保存的城市。尚在计算的分组标为整理中，不作为已完成的旅行。
5. 首批结果可用后允许查看；完整整理继续时不抢镜头、不自动切换用户正在看的旅行。中断保留已提交结果和可续扫状态。
6. 完成后更新摘要和最近旅行卡片，用户主动点“重走”。建议取消默认强制自动回放，保留减少动态效果偏好。
7. 常住判断和阶段命名在结果出现后按需提示，可跳过；不再把连续三问设为进入首页前的必经环节。
8. 成功导入后请求适用的平台存储保护；首次备份提醒放在合适的空闲时刻，不打断首次看旅行。

备注：渐进点亮、分批保存、查看中继续扫描涉及现有提交与分组机制的调整，需先设计中断恢复及稳定 ID，再实现；当前代码尚不完整支持这套目标行为。

### B. 日常回看旅行

打开地球 → 查看最近旅行摘要 → 点卡片 → 地球定位旅行、底部半展开 → 点照片看大图／点地点看该地照片 → 返回原旅行。

- 从“全部旅行”选更早的记录，取代首页卡片当前内容。
- 轻划卡片切换相邻旅行可作为后续增强；初版优先显式目录入口，避免横向滑动与地球手势冲突。
- 上次选择只在本次返回中恢复；跨次启动是否恢复上次旅行，留作讨论。

### C. 从地球找回忆

旋转／缩放地球 → 点城市 → 查看到访与照片 → 点某次到访／所属旅行 → 查看或回放 → 返回原城市。

用户手动拖动地球不触发时间范围变化；点城市也不自动把全年范围切回全部。

### D. 按年份或人生阶段看

点时间入口 → 选年份／阶段 → 地球和底卡共同更新 → 查看该范围旅行 → 重走此年／此阶段。

无旅行但有居住记录时，阶段仍可展示城市与照片；不制造旅行以填满界面。

### E. 重走旅行

点“重走” → 收起详情 → 镜头沿已知地点顺序移动，显示地点、已有日期和相关照片 → 播放结束停在该旅行全貌 → 可再次播放或分享。

- 播放时只保留暂停／继续、进度和退出；调速收进更多。
- 暂停后可查看照片与拖动地球；继续从当前位置对应的播放段恢复。
- 退出恢复进入前的筛选、镜头和底部内容；播放结束不自动公开分享。
- 地点之间使用推测连接，不声称真实乘车／飞行轨迹；无坐标地点可显示文字与照片，不编造飞行目标。

### F. 发现整理不对

旅行或城市详情 → “⋯／编辑” → 选择问题 → 预览影响 → 保存 → “已修改 · 撤销”。

- 标题不对：直接改标题。
- 同一城市重复：在城市详情选择合并对象，列出将合并的到访与照片；保留不同日期的到访。
- 两段旅行混在一起：按时间或照片选择拆分点，预览拆分后的两段；日期不充分时不自动选点。
- 一段旅行被拆开：选相邻旅行合并，展示合并后的日期、地点和照片。
- 照片放错：移到已有旅行、从该旅行移出，或据选择新建旅行；不删除系统原图。
- 某次只是路过／转机：调整这次到访；不把该城市其他年份的旅行全部改成路过。
- 地点不准：优先离线查找或地图点选；在线查询继续逐次明确同意。
- 不想展示：隐藏对应记录，并说明对地图、统计、回放和导出的影响；可撤销。

现有实现已经有可撤销改名、分类、合并、多站拆分与隐藏；按照片移归属、单城市按日期拆分和到访粒度调整仍需核对／补齐，不能当作现成能力。

### G. 新照片与补录历史

打开 App → 在已授权范围内增量整理 → 轻提示“新增一段旅行／补充了某段旅行的照片” → 点提示才定位。

导入历史照片不会把它们排成最近发生的旅行。不重复创建已知照片、地点和旅行；不覆盖人工修正。
权限不足或导入失败时保留已有记录，允许继续补充。网页仍由用户主动选择照片。
人工补录可只填地点和可选日期，不强制有照片；入口放在添加面板中。

### H. 分享与数据保护

当前旅行／城市／年份／阶段 → 分享 → 预览实际范围 → 选择照片和位置精度 → 明确生成／发布 → 系统分享或保存。

- 默认只包含用户主动选择的内容，保留现有住宅模糊和隐私审查规则。
- 初版复用已有 Story 预览、文件与静态 ZIP；海报是后续能力，不能画成已可用按钮。
- 托管分享按当前可用性标明服务边界，发布前明确上传内容；生成预览不等于上传原图。
- 备份由“我的”进入，展示成功／取消／失败及上次成功时间；提醒不抢占浏览。
- 恢复前说明影响并保留保护措施；缺原图显示占位，可用缩略图继续回看。

## 三、地点重复的规则

| 情况 | 地图／概览 | 详情与回放 |
|---|---|---|
| 同一行政城市的简称、全称、别名 | 统一显示，同一城市一个身份 | 保留原始观测与到访，支持纠正误合并 |
| 地级市与下辖区县等不同层级 | 默认采用统一城市层级，不把父级摘要当成额外一站 | 下辖地点作为细节；层级或归属不确定时保留未确认 |
| 同一城市有大量照片／拍摄点 | 概览显示一个城市标记，近看可展开已知地点 | 连续停留合并显示，照片仍各自保留 |
| 同一城市多年多次到访 | 地图一个城市点、显示到访次数 | 按日期分开，不能因名称相同合成一段旅行 |
| A→B→A 的真实折返 | 城市数为 2，概览城市名去重 | 停靠顺序可保留 3 段，不删除真实返回 |
| 同名但不同地区的城市 | 独立身份，必要时加地区后缀 | 不能仅凭名字相同合并 |
| GPS 漂移／边界附近跳动 | 结合行政归属、时间与相邻观测识别候选 | 不确定时提示，不能靠距离把真实两地强行合并 |
| 疑似跨设备重复照片 | 有可靠身份依据才去重 | 时间地点相同不等于同一张照片，不静默删除 |

标题优先使用用户命名或简短目的地组合，不把所有行政区全称拼进标题。
地图唯一城市、一次到访和旅程中的停靠是不同层次；规则先明确，再决定需要的数据结构。
展示去重不能删除照片证据，也不能改变已确认的到访顺序。

## 四、异常与返回规则

- 没照片：地球空状态，可选示例、添加照片或人工补录。
- 有照片无 GPS：保留照片，提供“未定位照片”入口；允许人工关联，不编造地点。
- 有城市无旅行：展示城市与照片，不把日常生活强行包装成出游。
- 无法确定最近旅行：提示日期未知，保留目录入口，不按导入时间伪装旅行日期。
- 当前范围没记录：显示明确空状态，提供切回全部时间，不偷换筛选。
- 缩略图／原图不可用：占位、权限说明和重试；不阻断地点与已有回放。
- 网络或地形加载失败：显示可用的地球与本地记录，提示缺失画面；已具备本地素材的部分继续工作，不承诺所有底图完全离线。
- 用户主动操作优先：扫描完成、轻确认、备份提醒与新旅行通知都不抢镜头或替换当前卡片。
- Android 返回键先退出当前子操作／播放，再收起底部内容，最后才离开主页面；退出前保留已保存状态。
- 桌面用同一信息结构，底部详情可换成侧栏；不增加另一套产品逻辑。

## 五、建议的实施切片

1. **首页与导航**：地球、单张最近旅行摘要、旅行目录、底部展开与返回、统一时间范围。先验证用户能找到并打开一段旅行。
2. **旅行详情与纠错**：照片／停靠层级、统一短标题、重复地点规则、现有编辑入口整合；补齐归属与拆分能力。
3. **回放与分享**：用户主动开始、清晰暂停退出、范围一致、分享审查与返回。
4. **渐进导入与人生阶段**：稳定分批保存、不中断浏览、可跳过确认、阶段范围与命名。

I3 仍拆时间轴／选择状态、飞行调度和卡片入口，但围绕上述用户路径收敛；
最小 SceneSlice 负责统一筛选与地图投影。人生色带时间轴的优先级需随本稿一起重评。

## 六、待讨论的取舍

- 初版是否认可“时间范围选择＋阶段列表”，将完整人生色带时间轴后移？
- 首页选中旅行后，重启恢复上次上下文，还是每次回到全貌＋最近旅行？建议初版每次回到全貌。
- 最近旅行摘要保留小封面，还是纯文字让地球更突出？建议小封面不超过卡片宽度四分之一。

讨论验收问题：用户能否在一次点按后看懂最近旅行；能否从地球找到同城某次到访；
能否发现并修正一次错误归并；能否随时回到原来看的地球与时间范围。
