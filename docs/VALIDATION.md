# 微缩地球验证记录

记录范围：2026-10-24 至 2026-10-25。CesiumJS 固定为 1.120.0，JavaScript ES Modules，静态部署。

## 2026-10-24 基线内容

- 全球 30 倍展示高程、256 × 512 桌面网格和双线性采样；雪线、山谷明暗、海岸色彩、星空和薄层边缘光调整。
- 七类原创三维植物，树冠加入分枝、非规则轮廓、明暗层次；历史卫星颜色、海拔、纬度和栖息地噪声驱动约 11,186 个全球候选，按分块和 LOD 加载。
- 六类核心模板加稀疏戈壁；白桦秋色/冬雪、春季樱花、草原草浪、雪山粒子与薄雾。湿地水色、城市孤立绿像素、树线及陡壁排除规则已收紧。
- 呼伦贝尔以草丛/灌木为主，那拉提保留山林；草原近看降至约 260 米观察距离，65% 草丛预算分配到 450 米以内，总量上限保持不变。
- 白天近景使用独立材质，局部云影与风向在 CPU 端统一转换；与足迹夜景的过渡平滑混合。近景各向异性采样上限桌面 4、受限设备 2，全球精细展示纹理不变。
- 真实地形射线求交改为有界空间索引：保留原始三角形、裙边、夸张参数和原求交算法。桌面缓存上限 16 项/24 MiB，受限设备 8 项/8 MiB；最多两个异步构建任务。
- 性能摘要默认折叠，包含相机/景观生命周期、实例、查询缓存、帧率和 GPU 抽样；详细 CPU 分析仅在 `profile=1` 开启，无遥测上传。

3. 本地引擎/Worker/许可文件、NASA 原图 SHA-256 校验与启动文件。

5. 直接加载仓库中的 Cesium 数学代码，619 组原生与索引射线比较，覆盖上下行、斜射线、裙边、边界、背面剔除、1/1.65/2.4 倍夸张及相对高度；最大位置差约 6.59 × 10⁻¹⁰ 米。另验证无效几何拒绝、过期/取消、缓存边界、离开释放与未来版本回退。

129² 高度图中心射线排除了至少 95% 的三角形测试。Node 数学内核采样约 42 ms → 0.12 ms，仅作内核比较，不作为浏览器帧率。JavaScript 语法和 `git diff --check` 通过。

## 浏览器实测

本机内嵌浏览器，Apple M1（ANGLE Metal）；不同窗口尺寸和自适应像素密度下的短采样窗口，不是统一基准测试。记录实际渲染像素，避免将不同视口 FPS 直接比较。屏幕模拟不等于手机硬件测试。

| 场景 | 实际渲染像素 | 实例 / 雾 / 粒子 | FPS 采样 | P95 帧间隔 |
|---|---|---|---|---|
| 京都，加速前对照 | 749 × 763 | 2250 / 3 / 40 | 14.1 | 约 77 ms |
| 京都，原材质加索引 | 749 × 763 | 2250 / 3 / 40 | 33–35 | 约 31 ms |
| 京都，当前日间近景 | 682 × 763 | 2250 / 3 / 40 | 35.5 | 32.4 ms |
| 白桦秋色 | 1004 × 898 | 2700 / 8 / 40 | 53 | 33.9 ms |
| 呼伦贝尔，当前低镜头 | 1204 × 1347 | 1209 / 2 / 40 | 51 | 32.6 ms |
| 上海 | 853 × 763 | 360 / 0 / 0 | 41.4 | 26.5 ms |
| 戈壁 | 853 × 763 | 240 / 0 / 0 | 37.9 | 29.1 ms |
| 高山大视口，优化过程 | 1230 × 1071 | 761 / 7 / 40 | 19.5–22 | 约 51–59 ms |

京都相同像素的 CPU 对照定位到原生地形高度查询：累计约 69 ms/帧；空间索引后约 0.35 ms/帧，标签更新约 0–0.1 ms。对照优化后连续采样窗口的长任务降至 0；初次解码、着色器与索引建立仍可能有长任务，不能声称从不掉帧。

地点间切换只保留一个景观；返回全球后，近景实例、模型、薄雾、粒子与地形查询缓存归零。演示模式返回首页仍显示原有 4 次旅行、5 个地点、23 天的示例数据。日夜与旅行回放使用原有流程。

## 边界与下一步

- 全球静止按需渲染，0 FPS 代表停止重复绘制。桌面 60 FPS、手机 30 FPS 是目标，当前大视口高山场景仍未达到；不能把低地/草原的结果推广到所有场景。
- 树木已是真正的三维网格，仍是程序化风格资产。参考图的精细枝叶、接触阴影、复杂山体和电影光照尚未完全复现；完整目标不能只以本轮性能修复判定完成。
- 薄雾与粒子使用受控数量的空间 billboard，全球云层为独立球壳；未实现昂贵的完整体积云或全局植被投影。
- 全球地表、DEM、海深与云图来自不同年代。地形/树木比例为艺术夸张；颜色推断不等于真实土地覆盖或当时天气，季节效果为主题表达。
- 地点影像、海拔及地名服务仍依赖联网；Esri 灰色缺失图回退可用父级，但当地清晰度受可用数据层级限制。未完成 Android/iPhone 真机验收。
- 地形加速钩子针对内部 `GlobeSurfaceTile.pick`，已锁定版本并保留原生回退；Cesium 升级必须单独回归，不能直接沿用性能结论。


## Scenic Earth 迭代：2026-10-25

本轮为全球 P0 的一次可运行交付，没有将完整参考图宣布为完成。核心变化：

- 新增独立的 Region/Biome 配置；树高、冠幅、横纵比例、密度和连续噪声一起控制冠层。欧亚草原低地保持开阔，东侧山地保留针叶/白桦；热带采用较宽的分层冠形。城市核心、绿色湖水、荒漠核心和雪线继续排除。
- 全球地表改为统一经纬网格：桌面 320×640、受限设备 128×256；在 30 倍基础高程之上，只对高于邻域的 DEM 山脊增加有界美术起伏。高原和海面不统一抬升。树根与实际三角平面求交，包含地球曲率；网格、植被与接触暗部通过 Worker 计算并转移缓冲。
- 一张小纹理烘焙树根接触暗部，地表只增加一次采样；纬度/海拔/坡向/山脊共同控制雪层，降低云层及云影遮挡。没有添加动态森林投影或体积天气。
- 浏览器实际渲染发现自定义网格在 Cesium 1.120 二维经线拆分路径存在半球缺失。Viewer 固定纯三维模式后，亚洲、欧洲、美洲和非洲地表均检查完整。
- 修复动画节拍累计漂移：固定目标时间轴吸收 RAF 抖动，长任务后跳过过期时隙，避免补画积压帧；正常静止与后台继续按需停止绘制。修正绘制指令计数的重置时机。
- 更新发布资源版本参数，避免旧模块、Worker 与新数据结构混用。保持静态部署、CSV 格式、单 Cesium 引擎；未引入原生 App 工程。

### 同条件性能对照

基线为 `900d9b8`，仅加入相同的相机、画质和测量入口。Apple M1 / ANGLE Metal 的内嵌浏览器；`benchmark=1` 固定相机、1 倍实际像素比并持续请求绘制，避免自转及自适应像素干扰。每组取就绪后最后 10 个两秒窗口的中位数。GPU 数值是整个 WebGL 提交区间，可能包含等待，不是纯着色器耗时。

| 配置 | 实际像素 | 实例 | FPS 中位数 | P95 帧间隔中位数 | GPU 区间中位数 |
|---|---|---:|---:|---:|---:|
| 旧版桌面 | 1448×1086 | 5212 | 51.5 | 33.05 ms | 7.28 ms |
| 本轮桌面 | 1448×1086 | 5230 | 60.0 | 19.55 ms | 8.06 ms |
| 旧版手机画质 | 390×844 | 711 | 26.0 | 50.6 ms | 1.97 ms |
| 本轮手机画质 | 390×844 | 715 | 30.0 | 36.95 ms | 2.17 ms |

新增地形细节有实际 GPU 成本；帧率提升主要来自节拍修复，不能归因于减少三角形。图形密度、像素比或真实手机 GPU 不同时，不能套用此表。正常静止场景停止重复绘制，0 FPS 为预期行为。初次解码与着色器编译仍可能有长任务。

亚洲、欧洲高山、欧亚草原、热带、非洲荒漠和美洲均留下实际渲染截图。跨区调参过程的 45–51 FPS 数据早于最后的节拍修复，单独标记为 calibration，不与最终版的 60 FPS 混用。手机列仅为本机执行手机纹理/实例/LOD/30 Hz 预算，**未完成 Android/iPhone 真机验收**。

### 距最终参考仍有差距

- 热带等部分树冠仍显程序化、重复，细密分枝和森林自遮蔽尚未达到参考图。
- 小范围山脉（如阿尔卑斯）的雪峰辨识度仍偏弱，全球雪岩和局部森林边界还需要按实际截图继续校准；颜色推断不等于可靠土地覆盖数据，不能保证每个湖岸/暗色城市都识别正确。
- 全球巨型森林到地点植被的尺度衔接尚未完成；现有高度交接带仍可能出现一段植被稀疏，不宣称通过完整视觉连续性验收。
- 参考图中的照片式地点标签、金色播放进度、原生 App 打包及手机真机验证尚未完成。

本轮结果和这些剩余项目一并交付；测试通过不代表整个 Scenic Earth 视觉目标已达成。
