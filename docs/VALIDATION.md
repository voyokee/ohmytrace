# 微缩地球验证记录

日期：2026-10-24。CesiumJS 固定为 1.120.0，JavaScript ES Modules，静态部署。

## 本轮内容

- 全球 30 倍展示高程、256 × 512 桌面网格和双线性采样；雪线、山谷明暗、海岸色彩、星空和薄层边缘光调整。
- 七类原创三维植物，树冠加入分枝、非规则轮廓、明暗层次；历史卫星颜色、海拔、纬度和栖息地噪声驱动约 11,186 个全球候选，按分块和 LOD 加载。
- 六类核心模板加稀疏戈壁；白桦秋色/冬雪、春季樱花、草原草浪、雪山粒子与薄雾。湿地水色、城市孤立绿像素、树线及陡壁排除规则已收紧。
- 呼伦贝尔以草丛/灌木为主，那拉提保留山林；草原近看降至约 260 米观察距离，65% 草丛预算分配到 450 米以内，总量上限保持不变。
- 白天近景使用独立材质，局部云影与风向在 CPU 端统一转换；与足迹夜景的过渡平滑混合。近景各向异性采样上限桌面 4、受限设备 2，全球精细展示纹理不变。
- 真实地形射线求交改为有界空间索引：保留原始三角形、裙边、夸张参数和原求交算法。桌面缓存上限 16 项/24 MiB，受限设备 8 项/8 MiB；最多两个异步构建任务。
- 性能摘要默认折叠，包含相机/景观生命周期、实例、查询缓存、帧率和 GPU 抽样；详细 CPU 分析仅在 `profile=1` 开启，无遥测上传。

## 自动验证

`npm test` 全部通过：

1. 植被总量与近处草丛预算、水域/屋顶/陡壁/树线排除、确定性分布、Worker 回退与取消。
2. 设备/GPU 纹理预算、全球与地形交接、坐标对齐、贴图失败回退、自适应像素与按需渲染、后台暂停恢复。
3. 本地引擎/Worker/许可文件、NASA 原图 SHA-256 校验与启动文件。
4. 七类可重复生成的 GLB、三维体积、单位法线、风摆 UV、实例化缓冲、连续近远 LOD、地点/季节规则及相机旧票据拒绝。
5. 直接加载仓库中的 Cesium 数学代码，619 组原生与索引射线比较，覆盖上下行、斜射线、裙边、边界、背面剔除、1/1.65/2.4 倍夸张及相对高度；最大位置差约 6.59 × 10⁻¹⁰ 米。另验证无效几何拒绝、过期/取消、缓存边界、离开释放与未来版本回退。

129² 高度图中心射线排除了至少 95% 的三角形测试。Node 数学内核采样约 42 ms → 0.12 ms，仅作内核比较，不作为浏览器帧率。JavaScript 语法和 `git diff --check` 通过。

## 浏览器实测

本机内嵌浏览器，Apple M1（ANGLE Metal）；不同窗口尺寸和自适应像素密度下的短采样窗口，不是统一基准测试。记录实际渲染像素，避免将不同视口 FPS 直接比较。屏幕模拟不等于手机硬件测试。

京都相同像素的 CPU 对照定位到原生地形高度查询：累计约 69 ms/帧；空间索引后约 0.35 ms/帧，标签更新约 0–0.1 ms。对照优化后连续采样窗口的长任务降至 0；初次解码、着色器与索引建立仍可能有长任务，不能声称从不掉帧。

地点间切换只保留一个景观；返回全球后，近景实例、模型、薄雾、粒子与地形查询缓存归零。演示模式返回首页仍显示原有 4 次旅行、5 个地点、23 天的示例数据。日夜与旅行回放使用原有流程。

## 边界与下一步

- 全球静止按需渲染，0 FPS 代表停止重复绘制。桌面 60 FPS、手机 30 FPS 是目标，当前大视口高山场景仍未达到；不能把低地/草原的结果推广到所有场景。
- 树木已是真正的三维网格，仍是程序化风格资产。参考图的精细枝叶、接触阴影、复杂山体和电影光照尚未完全复现；完整目标不能只以本轮性能修复判定完成。
- 薄雾与粒子使用受控数量的空间 billboard，全球云层为独立球壳；未实现昂贵的完整体积云或全局植被投影。
- 全球地表、DEM、海深与云图来自不同年代。地形/树木比例为艺术夸张；颜色推断不等于真实土地覆盖或当时天气，季节效果为主题表达。
- 地点影像、海拔及地名服务仍依赖联网；Esri 灰色缺失图回退可用父级，但当地清晰度受可用数据层级限制。未完成 Android/iPhone 真机验收。
- 地形加速钩子针对内部 `GlobeSurfaceTile.pick`，已锁定版本并保留原生回退；Cesium 升级必须单独回归，不能直接沿用性能结论。
