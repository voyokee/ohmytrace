# 全球地球渲染交付验证

日期：2026-10-24。保留 CesiumJS 1.120.0、JavaScript、静态部署和原旅行数据格式。

## 已实现

- 使用 NASA 全球地表、GEBCO 地形及海深数据、Black Marble 城市灯光和银河素材，全部保存在项目内并附署名及校验值。
- 独立地表、云层、大气三层渲染，统一经纬度与光源方向。地表含高度明暗、深浅海配色、海面反光、云影、城市灯光和足迹光效。
- 全球展示与真实卫星地形共用 Cesium 相机；下降时预加载地形，并在约 2400–650 公里之间平滑交接。远处停止绘制底层地形，资源失败时保留卫星地球。
- 首屏使用 2048 像素素材，地表随后异步升级到桌面 5400、触屏/内存受限设备 4096（受 GPU 上限约束）；已知不超过 2 GB 内存的设备保留 2048。辅助纹理保持 2048。桌面窄面板不再降为手机档，高分辨率静止画面关闭 FXAA。
- 保留日夜切换、年份筛选、旅行回放、地点近看、坐标校正、CSV 导入与导出。静止按需渲染，后台暂停。
- 官方 Cesium 浏览器构建、Workers、资源、许可及第三方声明一起交付，无前端安装或构建步骤。

## 自动检查

运行 `npm test`，或分别运行：

```bash
node tests/performance.mjs
node tests/rendering.mjs
node tests/delivery.mjs
```

检查通过：植被上限和任务取消、自适应分辨率、静止与动画档位及抗锯齿策略、设备内存/GPU 纹理预算、后台处理、交接过程始终保留至少一种地球渲染、地形预加载、未就绪回退、渐变单调性、经纬度对齐、素材 SHA-256、启动依赖与 Worker 本地化、许可文件完整性。JavaScript、Python 和启动脚本语法检查通过。

本地 HTTP 服务验证了首页、引擎、渲染模块、地表纹理、几何 Worker 和健康检查，响应为 200，并使用开发缓存策略。同一端口已有本应用时可复用服务。

## 浏览器验证

在本机内嵌浏览器使用虚构示例足迹验证，窗口为桌面 1448 × 1086、窄屏 390 × 844。窗口模拟不等于 Android 或 iPhone 真机测试。

- 验证全球日间与夜景切换、上海标记对齐、地点飞入、那拉提近看、返回全球，以及完整四段旅行回放。
- 实际交接记录包含 `earth → transition → terrain` 和 `terrain → transition → earth`；返回后植被对象归零，回放结束后恢复播放入口。
- 桌面全球开场动画的采样约 56–60 FPS；停稳后 0 FPS 表示停止重复绘制，不是页面失去响应。
- 首次交付版本的窄屏测试使用 2048 像素纹理，工具栏位于视口内，无横向溢出。后续清晰度修复改为按实际设备能力渐进升级贴图。
- 本次复查没有新增控制台警告或渲染错误。

清晰度修复复查：在实际 656 × 898、DPR 2 的桌面窄面板中，地表贴图从 2048 升级为 5400，静止画布从 984 × 1347 提升至 1312 × 1796。1280 × 720 的开场采样中，首个加载窗口约 30.5 FPS，后续飞行/自转窗口约 48.5–60 FPS；静止后继续停止重复渲染。触屏和低显存档位通过策略测试，尚未进行手机真机复查。

## 实际边界

- 那拉提近景 3300 个植被对象时，本机仍采样到约 13–14 FPS、P95 帧间隔约 79 ms。全球展示的性能改善不代表森林近景卡顿已解决。
- 真实地点的卫星瓦片、海拔及地名搜索需要联网；全球素材和 Cesium 引擎随包提供。
- 全球素材是不同年代的历史合成图。光照、浅海颜色、云影与大气经过艺术处理，不代表旅行日期的太阳位置、灯光或天气。
- 交付图是该版本的实际浏览器截图；参考图用于美术方向，并不代表像素级复刻。
