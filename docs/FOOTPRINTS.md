# 足迹与年份显示

底部「全部」展示完整旅行记录；选择年份后，地点、列表、统计、路线和足迹夜景使用同一时间范围。切换年份会回到概览并结束旧的回放/地点环绕，避免筛选后仍停留在上一段行程。重复选择当前年份不会切到全部；「全部」始终有独立入口。

跨年旅行计入每个重叠年份，按天填写的旅行天数只统计当年的部分。居住地点按其居住日期筛选；没有日期的居住地点保留作位置参考。日期未填写的旅行可在「全部」中访问。筛选不改写 CSV 或存储记录。

## 密集地点

- 屏幕上邻近的地点形成紧凑聚合，数字表示该组的地点数。聚合锚点使用组内真实地点，缩放后重新展开；不通过相邻点的传递链把整个区域合成一个长组。
- 现居地与选中行程有较高显示优先级；小幅相机变化保留已有锚点，避免频繁跳动。地点完整名称可在聚合菜单中访问，原有位置校正入口继续保留。
- 自动标签避让彼此、其他标记和界面面板，并限制显示数量。鼠标悬停或键盘聚焦可查看其余名称；地图数据没有因隐藏标签而删除。
- 全部模式按年份汇总密集时间轴，年视图按月份汇总；月份内多次旅行可展开列表选择。较小的示例仍保留逐次旅行的时间点。
- 全部概览不同时铺开所有路线。选中旅行时显示其路线；较小的年份集合可同时显示该年路线，避免线路遮住整颗地球。

窄屏年份条支持横向滚动，「全部」固定在左侧。按钮可用 Tab 访问，左右方向键及 Home/End 移动焦点，Enter/空格选择。聚合菜单可用 Escape 关闭并返回触发按钮。

## 模块与预算

`src/ui/year-scope.js` 统一年份、跨年天数和时间轴分组；`footprint-layout.js` 负责空间分组和标签避让；`footprint-overlay.js` 执行投影与 DOM 更新；`map-chooser.js` 复用地点及旅行选择菜单。相机、CSV 和行程调度继续由现有应用连接这些模块。

分组使用空间网格与确定性种子，不增加 Cesium 实体或三维模型。远景自动标签上限为桌面 6 / 窄屏 4，近景为 10 / 6；只有变化的可见性、位置和内容写入 DOM。标签尺寸按文字或视口变化缓存。静止时保留原有按需渲染。

足迹开场点亮的延迟窗口最多 3.2 秒；小数据仍保留原 420 ms 逐点节奏，大数据不会因地点数量增加而持续点亮近一分钟。这个窗口不等于完整应用加载耗时或 FPS 保证。

## 定位回退

省名搜索可能遇到境外同名公园、社区等结果。省级回退现在同时检查区域代码、行政层级和名称，使用 `countrycodes`、`featureType` 及 `addressdetails`；参数定义见 [Nominatim 官方 Search 文档](https://nominatim.org/release-docs/latest/api/Search/)。国际地点保持原有全球搜索。

“两省交界 + 景点”的描述增加去除边界描述的搜索词。旧的省级粗定位及未找到结果重试一次，并记录查询版本；用户提供/手工确认的坐标不会被这个重试覆盖。自动结果继续标为待确认，不能视为所有地点的精确定位验收。

## 验证边界

原有测试保留，新增跨年日期、未知日期、居住区间、紧凑分组、地点数量守恒、种子稳定、标签避让和定位范围测试。浏览器实际检查了多年份大数据、聚合列表、时间轴旅行选择、键盘、导出及 390×844 窄屏；私有样本及其截图用于本地验证。

这些检查不等于手机真机或持续帧率验收。全球森林、雪山与全球至近景的完整视觉衔接目标继续保留，区域森林仍为默认关闭的开发预览。
