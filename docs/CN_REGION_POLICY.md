# 国内地区口径与离线查询（I2-A/B）

## 唯一口径（`src/life/geocoding/region-policy.js`）

`regionOf(code, admin1)` 是无副作用的名称、归属与类别查询，支持包内
ISO3、在线 ISO2 和存量中文名称。`countsAsCountryKey` 返回统计归属；
克什米尔争议条目返回空值。包内 242 个名称的静态表来自已锁定的
`data/index.json`，不依赖网络或新的运行时包。

中国大陆、台湾、香港、澳门均归入 CHN；显示为中国、中国台湾、中国香港、
中国澳门，香港与澳门的城市名仍是香港、澳门。韩国、朝鲜使用简称，
澳属印度洋领地使用简体。科索沃归 SRB、塞浦路斯北部归 CYP、索马里兰归 SOM。
印度包中阿鲁纳恰尔邦覆盖为中国 / 西藏自治区（藏南地区）。
争议项均为产品执行目标的默认值，**待法务复核**。

本机制只处理地名解释，不修改 Natural Earth 原始几何、不变更底图或国界线。
藏南、阿克赛钦、克什米尔精确边界未实现；admin 级覆盖只是近似。
钓鱼岛代表坐标在当前数据中没有名称；测试锁住不得解析成日本。

## 反查与存量读取（`provider.js`、`first-use.js`、`journey-title.js`、`renderer-adapter.js`、`record-card.js`）

离线、在线及缓存反查出口统一归一化；`countryCode` 保留上游原始代码，
增加 `sovereignCode`，不更改 schema v1 的集合或必填字段。
同一结果多次归一化保持一致，包括藏南覆盖。

揭晓与首页统计用归属去重，文案为“国家 / 地区”。旅程标题比较归属而非
国家字符串：中国大陆至港澳台仍是旅行，使用城市标题。
旧 `photoCity` 的名称在读取时解释；城市卡片显示映射后的地区，人工名称保留。
重复地点的显示后缀、卡片关联列表也使用同一名称函数。旧的自动旅程标题在
卡片、地图投影与故事编排时按保存的照片观测重新解释；人工旅程标题不改。
分享产物采用故事中的可见旅程标题，避免在元数据中残留旧自动标题。

## 升级（`offline-admin-resolver.js`、`media/auto-import.js`）

离线 resolver ID 与 Cache Storage 名均升级为 `*-zh-city-cn-v3`，旧地名缓存
不再命中。自动整理版本从 4 升为 5，沿用既有重整 / 原生升级扫描机制。
重新整理会持久化新地区字段，并保留照片和地点 ID、人工改名、分类、合并和拆分。

## 离线正向搜索（`offline-admin-resolver.js`、`scripts/prepare-admin-search.mjs`）

默认搜索使用 7,324 个城市点、国家索引及派生的行政区搜索索引。
`admin-search-index.json` 有 4,580 个行政区代表点和城市对应的中文行政区名，
由捆绑几何生成：`node scripts/prepare-admin-search.mjs`。
代表点仅用于推断定位，不表示实测地点或精确行政中心。
索引在首次搜索时加载一次，避免每个查询读取 242 个几何包。

支持全名、去市 / 县 / 区 / 省等后缀以及包含匹配，保留省份 / 国家筛选。
返回坐标、显示名、类别、排序权重、来源“离线”和 `inferred` 状态。
未知景点保持未定位，不把所属省中心伪装成景点坐标。

## 在线单点同意（`app.js`、`provider.js`、`online-geocoder-adapter.js`、`legacy.js`）

启动、CSV 导入 / 编辑、记录恢复与照片重整只走离线。
地点校正中展开“搜索其他位置”，可离线查找或“在线查找”。后者先显示
将发送的单个名称与 OpenStreetMap 境外服务说明；取消不请求，同意只发这一条。
provider 和在线适配器都校验同意，命中在线缓存也须先同意。
请求串行、保留节流，并正确绑定原生 fetch 的 Window 接收者。
自动坐标证据记录实际 provider，离线结果不再写成 Nominatim。

照片重整验收通过。全部 242 个包的名称通过 resolver 出口扫描。
桌面浏览器使用 Playwright 1.55.0；数据为合成夹具，不代表真实相册或真机验证。
帧率协议与原始窗口保存在 `cn-policy-performance.json`；不是 Android 性能证据。
