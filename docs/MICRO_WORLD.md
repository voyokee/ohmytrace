# 微缩世界实现与调整

本版保留 CesiumJS 1.120.0、JavaScript ES Modules 和静态部署，没有切换引擎或升级 Cesium。

## 全球与地点

全球展示在 WGS84 椭球网格上双线性采样本地历史 DEM，将高程夸张 30 倍。桌面基础网格为 320 × 640 分段，受限设备为 128 × 256；`surface-topology.js` 按真实海拔及局部高差选择山地，最多细分 7% / 5% 的地块。山地以半步长采样原 DEM，粗细交界共用边界中点，避免裂缝；平坦海洋与高原不统一加密。近景会换回 Esri 实际地形的 1.65 倍夸张。全球树木有意放大，不能作为实际高度测量。全球树根、地表贴图、地点标记均以经纬度对齐。`world-elevation.js` 在 30 倍基础之上只增强 DEM 高于邻域的山脊（`WORLD_RIDGE_RELIEF=72`），再按山脊高于邻域的相对比例乘以 0.55–1.60 的平滑增益：较低山麓上的独立山脊更醒目，高原上的小起伏适当收敛；新增山脊位移上限为 150,000 艺术米，不整体抬高平坦高原、海岸与湖泊；这些参数是微缩美术尺度，不能用于真实海拔测量。

`world-data.js` 根据历史卫星颜色、海拔、纬度推断森林，排除蓝/绿色水域、雪区、树线和历史城市灯光图中明亮的城市核心。`world-biomes.js` 提供独立于 Cesium 的区域规则：寒温带、白桦、温带、热带、山地、草原。低频连续噪声控制林缘和冠层高度，树高、冠幅、横纵比例和密度共同变化；呼伦贝尔低地限制为少量树群，东侧大兴安岭保留森林。它不是土地覆盖数据库，小岛、湿地、模糊海岸及暗色城市仍可能有识别误差。

`forest-form.js` 在合格候选上添加区域冠层结构：2.4 度的连续场组织林间空地，0.65 度的场组织低层与高树；经度接缝平滑环绕。针叶林偏瘦高、阔叶及热带林偏饱满，少量温带山地高树改用针叶树。高树和较低冠层进一步拉开，针叶高树使用较小高度增幅和较宽冠幅，避免过尖。针叶树高超过 300,000 艺术米后渐近 420,000 上限，阔叶/白桦/热带树在 200,000 后渐近 290,000，避免宽大冠层过分突起。冠幅随高度共同调整；海拔达到所属树线的 40–95% 时，连续压低高树，山地压低幅度更大，让山脊露出。宽冠树的长短轴比例扩大到 0.65–1.45，针叶候选保留 0.80–1.20，减少一致的圆形投影。四向高程采样进一步收缩海岸冠幅，但不是精确的海岸掩膜。保留候选随机流、原根点和地表三角形接触，不增加实例、网格或运行时纹理采样。`makeWorldForest` 的 `canopy:false` 仅用于开发对照。

`world-surface.js` 用同一套自适应拓扑生成 WGS84 三维地表，树根沿地理垂线与实际粗网格、细网格或过渡扇形的三角平面求交，包含地球曲率。面积加权法线让大坡面连贯，材质在山脊适量混合真实面法线。网格、细分标记、森林和接触暗部在 Worker 中生成并转移缓冲；主线程直接安装细分标记，避免首个地点标签重复扫描全球地形。高度缓存固定上限约桌面 6.3 MiB / 受限设备 1 MiB；按高度图弱引用缓存，不随相机移动增长。无 Worker 时网格构建、法线累计与归一化均协作让出主线程。Viewer 使用纯三维模式，避开 Cesium 1.120 对此自定义全球网格的二维经线拆分问题。

`canopy-contact.js` 按实际树根和冠幅烘焙接触暗部，不增加动态投影灯或树木绘制次数。桌面 1024×512（2 MiB）、受限设备 512×256（0.5 MiB），地表只增加一次贴图采样；同一纹理的第二通道轻调草原地色。雪线结合纬度、高程、坡向、山脊及影像已有积雪；凸起的 DEM 峰顶可补充窄雪帽，平坦高原不因此增加覆盖，仍受雪线和朝上坡面限制。复用原来的四向高程采样，不增加纹理查询。云层降低到约 170 公里艺术高度，减轻云影遮挡。

全球采样间距为桌面 0.48°、手机画质 0.72°，经度按纬度余弦调整；手机由原 0.96° 适度补密，仍最多 6000 个全球候选，只使用低精度模型。`world-forest.js` 按 24° × 18° 分块，优先相机正面，桌面最多 28 块，受限设备 12 块。高空使用低细节库；低于 4800 公里时只将最近四块升级为详细库，高于 5200 公里后恢复低细节，迟滞避免往返抖动；受限设备始终低细节。替代模型入场准备 GPU 资源期间保留旧模型，就绪后逐块替换，待准备模型与并行请求合计最多两个。分块移入时先回收不再需要的旧块，不突破常驻上限；进入地形近景后立即释放常驻与待替换模型。失败按退避时间重试，单块最多四次。

## 资产与近景

`vegetation-assets.js` 生成针叶、阔叶、白桦、热带、灌木、樱花与草七类真正的三维网格。阔叶与热带使用六组主枝冠层，白桦四组细长冠层，樱花保留十二个小叶簇；冠层带偏斜、不规则分瓣和部分面法线，使受光更清楚。阔叶与热带的主枝中心适度靠拢、枝冠相交，顶部更饱满，减轻放射状叶簇的形态；原有三角形预算不变。近远模型共享主枝中心及比例，包围盒尺寸差小于 15%；低细节逐树三角形预算保持原值，详细模型减少面数。TEXCOORD_0 的 X 存储归一化高度，Y 标记落叶树种；TEXCOORD_1 的 X 存储形状柔性，Y 区分枝叶与木质，使秋色只染叶片，保留白桦树皮。叶簇下部带轻量静态明暗。GLB 是原始代码生成资产，采用本仓库 MIT 许可。详细库 460,752 字节（约 450 KiB），低细节库 144,768 字节（约 141 KiB）。

```bash
node scripts/build-vegetation-assets.mjs
npm test
```

`instanced-vegetation.js` 使用 glTF `EXT_mesh_gpu_instancing`。全球 `canopy-shader.js` 从实例变换恢复树根和轴向，按确定性逐株种子收缩部分冠幅和高度、轻调叶色，不增加实例缓冲或绘制次数。该钩子依赖 Cesium 1.120 的实例化阶段，其他版本禁用形状变换；比例不超过 1，根点不动，原始包围盒包含根点，因此不会扩大裁剪范围。每个分块有独立 Blob URL，防止引擎缓存复用其他分块的实例缓冲；就绪、失败、取消或销毁后撤销 URL。桌面近远 LOD 在 2.8 公里交接，9 公里外不绘制；受限设备只加载低细节库。风摆用归一化网格高度，避免把实例化后的世界坐标当作树木局部坐标。

全球树冠另按树根地理垂线与视线夹角控制地平线轮廓。背面或掠射视角的实例向原根点平滑收缩，正面的实例保持完整，避免树根被地球遮住而夸张树冠像卫星一样悬空；近远模型使用同一规则，近景地点植被不受影响。仍只收缩几何，不扩张裁剪包围盒，也不增加半透明绘制通道。

`SceneryManager` 管理 preload、enter、populate、update、exit、dispose。一次只保留一个地点，切换取消旧任务。进入时保存地面色调和雾，退出恢复。显式「近看」且已有地面海拔时，在飞行开始就复用地点加载流程；模型、薄雾、粒子仍按距离裁剪，未知海拔继续采用到达后加载。旧飞行与地点任务通过原代次及 AbortSignal 取消。

`scene-templates.js` 提供六类核心场景，另有戈壁扩展：

| ID | 场景 | 默认效果 |
|---|---|---|
| mountain_forest | 雪岭山林 | 针叶/阔叶、薄雾、浮尘 |
| birch_forest | 白桦薄雾 | 白桦/针叶、林间雾 |
| grassland | 风过草原 | 草丛/灌木，保留影像识别的针叶/白桦林、风、萤火 |
| alpine_snow | 雪山云谷 | 稀疏高山林、云雾、雪 |
| sakura | 樱花微雨 | 春季樱花/花瓣，其余月份阔叶 |
| coastal_city | 海岸之城 | 稀疏阔叶、较少雾 |
| desert | 戈壁微风 | 稀疏灌木和草、低密度裸地分布 |

可向 `sceneTemplateFor` 传入 `template` 显式指定，否则按地点名称、纬度和海拔选择。每类模板也可配置 camera.range/pitch；草原镜头约 260 米观察距离，近处草丛获得 65% 的草丛预算，高山适当拉远。呼伦贝尔以草丛/灌木为主，那拉提保留影像推断的山林。白桦 9–10 月转金色，11–2 月有覆雪与飘雪；南半球月份平移半年。新地点应先校验坐标，再调整种类、密度、树线、雾与色调。`terrain-placement.js` 复用已采样海拔，拒绝邻近高差显示为陡壁的树木，不增加地形网络请求。

`EffectManager` 使用少量局部雾片与最多 40 个粒子（受限设备 18 个），15 Hz 更新粒子；雪/花瓣下落、萤火随夜色增强。`prefers-reduced-motion` 会停用动画。

`CameraDirector` 用代次票据保护全球、飞入、地点、沉浸、离开状态；旧飞行完成回调不能覆盖新镜头。回放复用现有旅行调度。

## 地形查询与近景开销

`terrain-picking.js` 仅在 Cesium.VERSION 为 `1.120` 时包装 `GlobeSurfaceTile.pick`。只处理实际渲染的原始 HeightmapTerrainData 网格、三维场景和低于 1000 公里的相机；填补网格、二维、未来版本等均使用原算法。此钩子属于内部接口，升级引擎时必须重新核验。

空间索引保留原始三角形、裙边和夸张高度，用地块 ENU 坐标中的保守包围盒裁剪候选，再调用 Cesium 原来的射线/三角形求交。没有降低地形分辨率或近似插值。异步构建定期让出主线程，最多两个任务；桌面最多 16 项/24 MiB，受限设备 8 项/8 MiB。网格、缓冲区或夸张参数变化时失效，离开低空时清空，销毁时恢复原方法。无效/过期/待构建数据回退原算法。

`terrain-daylight.js` 将近景白天的坡面明暗、云影、草浪与空气透视从夜色材质中独立出来。局部坐标和风向在 CPU 端每帧转换，片元着色不再重复计算全球足迹池。日间地形与展示层在 2400–650 公里之间平滑交接，夜景仍保留足迹池。近景影像各向异性采样上限为桌面 4、受限设备 2；全球 5400 像素展示材质不受此项影响。高海拔雾效按地点地面海拔补偿，远处雾中的地形使用较高 SSE 预算，退出时恢复原设置。

## 调参与边界

- 冠层高度只保留一次高层增益，取消与它相关的第二次增益，避免低层过薄、高层过尖；`CANOPY_CEILINGS` 中针叶软拐点 230000 / 尾长 70000，宽冠 190000 / 65000 艺术米，渐近上限分别为 300000 / 255000。接近树线时，山地冠层进一步连续收至 45%、其他林地至 70%，让裸岩山脊露出；岛屿冠幅收缩继续生效，逐株宽度仍随高度比例补偿。没有增加候选、改变根点或替换已认可的主枝树冠模型。性能面板的 `worldCanopyHeights` 是 Worker 建林时按树种统计的全球候选高度分位数，尚未经过视距/地平线着色收缩，不代表实景物理树高或当前可见实例；排序只发生在建林时。
- 山麓冠层复用原有四个冠幅边缘 DEM 探针，在邻近高地相对根部升高 250–900 米、且高地超过 900–1800 米时连续收紧，最大高度/相对冠幅系数为 45% / 80%。平坦低地、平坦高原及向下的水域不触发山脊适配；树木资格、根点、候选、角度和长短轴保持原值。`worldCanopy.reliefFitted` 记录适配权重大于 0.05 的全球候选数。全球层显式传递 1 亿米远裁剪距离，避免较矮的山地冠层被模型加载器误当作近景树木。
- 雪帽补偿结合源影像的明亮中性色、正局部凸起、崎岖度、海拔/纬度雪线、坡面与陆地条件；源积雪权重平方压低普通灰岩的影响。它只补偿窄雪峰被粗高程平均压低的问题，不降低整条全球雪线，没有新增纹理采样。大陆山体仍来自原 DEM，影像和粗高程均有历史/分辨率限制，不能把补偿视为实时雪况。
- 地形比例：`world-elevation.js` 中的 `WORLD_RELIEF`、`WORLD_RIDGE_RELIEF` 和 `WORLD_RIDGE_MAX`；全球树高、冠幅与密度：`world-biomes.js`、`forest-form.js` 和 `makeWorldForest`。
- 雪线、浅海、云影和空气边缘：`earth-materials.js`。`sunlight.js` 让全球、真实地形、植被及云影投影共用同一相机方向的艺术光源，不按日期模拟太阳。
- 整体美术优先于枝叶细节：深蓝海洋到蓝绿大陆架采用历史海深分布，降低原底图烘焙明暗的重复影响；雪帽与裸岩分层，窄山脊的雪线只作小范围分辨率补偿，仍受纬度、海拔、坡面与源影像约束。高光用保留色相的肩部压缩，避免沙漠和雪山直接截白。树冠受光偏暖、阴影偏冷，星空降低灰底。默认全球构图半径提高，benchmark 保持旧相机取景，确保同条件性能比较。
- 整体色调校准进一步收窄高亮浅海的深度范围、降低青绿色亮度与深海数据块的对比，减少宽色带压过陆地；雪线分辨率补偿从 0.10 收至 0.04，积雪更偏高峰及朝上的坡面，保留岩壁和高原的裸地。全球森林降低均匀环境光、提高朝阳面的受光差异。没有为这次色调调整增加网格、实例或纹理采样；这些参数是统一美术光照，仍需继续靠近参考图的精细程度。
- 星点仅在加载/尺寸变化时绘制，蓝色边缘光位于 WebGL 后方，不模糊地表。
- `render-policy.js` 的动画节拍以首个实际更新为原点，使用四分之一时隙的容差，让 1–3 ms 动画时钟抖动远离选帧边界；同一时隙只绘制一次，维持 30/60 Hz 调度；长任务后直接跳过错过的时隙，不补画积压帧。正常静止/后台仍停止重复绘制。
- 节拍优先读取 `document.timeline.currentTime`，与浏览器 RAF 共用动画时间，避免 `preUpdate` 前的 CPU 工作改变时隙判断；不可用时回退传入的单调时钟。性能面板的 cadenceClock 显示实际时钟。标准依据：[Web Animations 文档时间轴](https://www.w3.org/TR/web-animations-1/#document-timelines)。此处没有另建 RAF 循环或替换 Cesium 的更新调度。
- `camera-motion.js` 用实际世界位置、视线与上方向判断运动，停稳 800 ms 后允许恢复静止高清；使用按观察高度缩放的亚像素容差，避免原生 moveEnd 事件未结束时长期停留在动画画质。日夜及足迹光效动画期间保持动画预算，完成后再回到高清按需渲染。指标同时保留原生事件状态与实际运动状态，便于核对。
- 性能面板 `?perf=1` 默认折叠，提供地球交接、实例/分块/LOD、雾/粒子、相机状态、查询缓存与帧率；展开后可隔离树木、材质、大气及局部特效。`&profile=1` 额外计时 CPU 调用，计时值有包含关系，不能相加。GPU 查询每 12 帧抽样，最多三个在途查询，结果为 WebGL 提交区间，可能包含等待 CPU 的空闲，不等同于着色器独占耗时。`?probe=1` 的红点是开发坐标校准。`&profilegpu=1` 增加实际绘制次数及三角形计数，包含实例数；不使用逐绘制 GPU 计时，也不读取像素。
- 可复现比较：`?perf=1&profile=1&profilegpu=1&benchmark=1&view=asia` 固定相机和 1 倍实际像素比，持续请求绘制，关闭开场自转与自适应分辨率。可选 `view=alps/americas/steppe/tropics/desert/birch/hainan`；`altitude=300000&pitch=-45` 可固定中景海拔及倾角（pitch 仅在 benchmark=1 生效，范围 −90° 至 −15°，默认 −90°）；`&quality=mobile` 执行手机的纹理、实例、LOD、并发与帧率预算。这是画质配置测试，不能替代 Android/iPhone 真机。省略 benchmark 时保留正常按需渲染和自适应。
- `?demo=<模板 ID>` 使用内存中的虚构景观数据，忽略并保护原有本地足迹；`&month=10` 可验收季节，返回首页恢复正常数据。配置在 `scene-demos.js`。
- 「森林 LOD 对比」在固定相机下强制最近四块切换精度，受限设备仍保持低细节。worldStaging、worldDetailed 可检查替换数量。
- 性能面板另报告 worldSurfaceTriangles、worldSurfaceVertices、worldMountainCells，可核对山地细分的实际成本；细分只在加载时计算，摄像机运动不重建地表。
- `&trace=1` 额外保留最近 240 次更新的动画时钟、CPU 开始与绘制完成时刻，写入性能面板的 data-frame-trace，仅本地诊断、默认关闭；离开页面清理监听器。平均 FPS 与帧间隔平滑度分开判断，当前手机画质仍有间隔波动。
- 开发预览 `?regional=1` 才启用 `RegionalForest`，默认关闭；中景树冠可见性已经改善，完整区域分布和尺度衔接仍未通过视觉验收，整体页面保留原森林展示逻辑。原型可用 `?regional=1&perf=1&profile=1&benchmark=1&view=birch&altitude=300000&pitch=-45` 检查。实现：在已知飞行目标处提前准备，区域植被从约 2400 公里渐入，按 1024 / 256 / 64 / 16 / 4 公里半径五级覆盖，最后与地点三维模型重叠退场。区域继续复用低精度 GLB 与 GPU Instancing；每套最多桌面 900 / 手机画质 220 株、4 个地理块，最多两套集合（峰值 1800 / 440 株、8 个模型）、一条地形采样任务及两条 GPU 准备任务。原集合保留到新集合所有模型就绪，再交叉淡化。地面采样使用原 Esri 地形 6 / 8 / 10 / 12 / 14 级，海平面及树线以上点过滤。公共 Cesium 采样请求不能逐项取消，退出用代次拒绝旧结果；GPU 加载任务使用 AbortSignal。区域资格仍依赖粗历史影像，分布与交接美术尚需校准，不能将这层初版当成完整连续性验收通过。
- 启用区域预览时，全球冠层从 6000 公里到 2400 公里先收缩到原尺寸的 28%，再随展示层退场收至 8%；避免中景仍充满数百公里高的全球巨树，也保留过渡早期的可见冠层。正常首页不启用这条曲线，保留原全球树冠比例。手动缩放低于 20 公里时，以每 600 ms 最多一次的原生地形射线取得离地高度，已知飞行目标复用目标高度；地形尚未加载时回退椭球。区域经度网格按已量化的纬度行计算，避免相机或地形高程的微小变化横向移动锚点、重置整片森林。
- 区域模型的 `_SOURCE_POSITION` 与原 POSITION 共用同一 accessor，不增加几何缓冲；专用顶点着色从原模型坐标重建根点及尺寸，避开 Cesium 1.120 在自定义着色之前执行的近似地形夸张。根高在 CPU 按真实采样高程及当前夸张计算一次，缩放始终不超过实例包围盒。此路径限定为 1.120，其他版本禁用区域层以保留原渲染回退。
- 日间真实地形在 2400–650 公里的展示层交接区间转亮，避免在未到访地点先陷入足迹夜色、到 160 公里以下才恢复白天。夜景模式仍由原足迹材质控制。区域树高以离目标地面的高度决定：中景基准为观察高度的 5%，上限 24,000 艺术米（原为 1.4%、上限 6,000），300 公里处基准约 15,000；在离地 14–1.2 公里区间平滑回到基准 22 米。原模型包围盒按上限生成，着色只收缩，每株仍带原有 0.7–1.3 比例差异。区域与全球冠层采用同一明暗强度，不增加几何和实例预算；实际像素覆盖增大会有填充成本。性能面板增加 regionalTreeHeight，便于检查当前美术比例。只有地点景观 ready 后才按近景交接淡出，加载较慢时保留区域层。
- 模型仍为紧凑的程序化美术，距参考图的精细枝叶、复杂地形和电影级光影仍有差距。Esri 缺失影像占位图会被识别并退回可用父级，回退后清晰度受当地数据层级限制。近景地形与影像服务仍需联网；不能把桌面目标 60 FPS、手机目标 30 FPS 作为实测保证。

## 后续 App 方向

地理采样、Region/Biome、分布、地表与资产生成均为独立模块，界面和 CSV/localStorage 保持原格式，便于以后由 WebView 或其他 App 容器复用。当前交付仍是静态 Web 项目；原生打包、触控设备调优、离线地点影像和云同步尚未实现。
