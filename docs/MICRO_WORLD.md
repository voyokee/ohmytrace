# 微缩世界实现与调整

本版保留 CesiumJS 1.120.0、JavaScript ES Modules 和静态部署，没有切换引擎或升级 Cesium。

## 全球与地点

全球展示在 WGS84 椭球网格上采样本地历史 DEM，将高程夸张 22 倍。它是展示用地形，近景会换回 Esri 实际地形的 1.65 倍夸张。全球树木有意放大，不能作为实际高度测量。全球树根、地表贴图、地点标记均以经纬度对齐。

`world-data.js` 根据历史卫星颜色、海拔、纬度推断森林，排除蓝色水域、雪区与树线以上区域。针叶/阔叶混合、东北白桦、低纬热带林具有不同冠形。它不是土地覆盖数据库，小岛与模糊海岸仍可能有识别误差。

`world-forest.js` 按 24° × 18° 分块，优先相机正面，桌面最多 28 块，受限设备 12 块，最多两个并行模型任务。高空使用低细节库；较近时切换详细库，进入地形近景后释放。失败按退避时间重试，单块最多四次。

## 资产与近景

`vegetation-assets.js` 生成针叶、阔叶、白桦、热带、灌木、樱花与草七类真正的三维网格。树冠含分层枝叶、平滑法线、线性顶点颜色和风摆高度坐标；GLB 是原始代码生成资产，采用本仓库 MIT 许可。

```bash
node scripts/build-vegetation-assets.mjs
npm test
```

`instanced-vegetation.js` 使用 glTF `EXT_mesh_gpu_instancing`。每个分块有独立 Blob URL，防止引擎缓存复用其他分块的实例缓冲；就绪、失败、取消或销毁后撤销 URL。桌面近远 LOD 在 2.8 公里交接，9 公里外不绘制；受限设备只加载低细节库。风摆用归一化网格高度，避免把实例化后的世界坐标当作树木局部坐标。

`SceneryManager` 管理 preload、enter、populate、update、exit、dispose。一次只保留一个地点，切换取消旧任务。进入时保存地面色调和雾，退出恢复。

`scene-templates.js` 提供六种配置：

| ID | 场景 | 默认效果 |
|---|---|---|
| mountain_forest | 雪岭山林 | 针叶/阔叶、薄雾、浮尘 |
| birch_forest | 白桦薄雾 | 白桦/针叶、林间雾 |
| grassland | 风过草原 | 草丛/灌木，保留影像识别的针叶/白桦林、风、萤火 |
| alpine_snow | 雪山云谷 | 稀疏高山林、云雾、雪 |
| sakura | 樱花微雨 | 春季樱花/花瓣，其余月份阔叶 |
| coastal_city | 海岸之城 | 稀疏阔叶、较少雾 |

可向 `sceneTemplateFor` 传入 `template` 显式指定，否则按地点名称、纬度和海拔选择。每类模板也可配置 camera.range/pitch；草原镜头更低，高山适当拉远。草原在草甸上生成成片草丛，影像已识别为森林的区域保留树木。新地点应先校验坐标，再调整种类、密度、树线、雾与色调；不要通过改动旅行数据来伪造景观。

`EffectManager` 使用少量局部雾片与最多 40 个粒子（受限设备 18 个），15 Hz 更新粒子；雪/花瓣下落、萤火随夜色增强。`prefers-reduced-motion` 会停用动画。

`CameraDirector` 用代次票据保护全球、飞入、地点、沉浸、离开状态；旧飞行完成回调不能覆盖新镜头。回放复用现有旅行调度。

## 调参与边界

- 地形比例：`WORLD_RELIEF`；全球树冠比例和空间密度：`makeWorldForest`。
- 雪线、浅海、云影和空气边缘：`earth-materials.js`。太阳为相机方向的艺术光源。
- 星点仅在加载/尺寸变化时绘制，蓝色边缘光位于 WebGL 后方，不模糊地表。
- 性能面板 `?perf=1` 提供地球交接、实例/分块/LOD、雾/粒子、相机状态与帧率，并可隔离树木、材质、大气及局部特效。`?probe=1` 的红点是开发坐标校准，不应在展示时打开。
- 模型是紧凑的程序化美术第一版，距参考图的精细枝叶、复杂地形和电影级光影仍有差距。Esri 缺失影像占位图会被识别并退回可用父级，回退后清晰度受当地数据层级限制。近景地形与影像服务仍需联网；不能把桌面目标 60 FPS、手机目标 30 FPS 作为实测保证。
